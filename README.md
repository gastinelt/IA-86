# IA86 (nom provisoire)

Projet au long cours de Théo Gastinel : étudier l'architecture **IA-64** (Itanium, principe EPIC), analyser son comportement et ses points critiques, puis concevoir une nouvelle base de langage machine qui en corrige les défauts.

## Phases prévues
1. **Comprendre** : lire le manuel Intel, fiches d'étude en français.
2. **Analyser** : critiques (articles, forums, retours d'expérience), verdict par point.
3. **Expérimenter** : simulateur d'un sous-ensemble d'IA-64.
4. **Refaire la base** : spécification d'un nouveau jeu d'instructions, assembleur, simulateur.

## Organisation
- `documentation/intel/` : manuel officiel Intel Itanium, révision 2.3 (mai 2010), 4 volumes. **Non versionné** (documents Intel sous droits) : à récupérer chez Intel.
- `documentation/recherches/` : notes de recherche (critiques, sources).
